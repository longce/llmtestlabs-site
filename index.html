Overview

From one sentence to a running test

Natural language driven: one sentence to test cases

Users only need to enter one sentence or a short test requirement (e.g. “Change system language to English in Settings”, “Create contact Zhang San, phone 188xxxx”) — no script writing or operation recording required.

The agent uses large models to understand test goals and business semantics, automatically breaks them down into executable test step sequences (click, input, swipe, assertion, etc.), and writes them into the case step list.

Supports both free-form description and continuation/planning based on existing steps: you can generate a full flow from scratch or extend and optimize existing cases.

Agent self-planning: from goal to script automatically

Goal understanding: Parse natural language requirements into structured intents such as “what to test”, “which screens to operate on”, and “expected results”.

Interaction prediction: Based on device type, screen semantics, and usage patterns, automatically predict reasonable interactions and generate test scripts that match real usage.

Step generation: Convert predictions into standardized test steps (element click, text input, property assertion) and insert them into the case to form complete, reusable test cases.

Autonomous execution and closed-loop verification

After steps are generated, the agent can execute them automatically on connected real devices and environments, achieving a “generate then execute” closed loop.

During execution it reacts to actual UI feedback (dialogs, error messages) and proactively asks the user when uncertain. After the user replies, it continues execution or adjusts the plan — the Agentic “sense–decide–execute–re-decide” loop.

Human takeover supported: pause auto execution at any time, switch to manual operation and add instructions; the agent then continues with the remaining steps.

Multi-scenario and extensible

Supports Web, Android, iOS, Windows, Mac, HarmonyOS and more. The agent chooses appropriate actions and assertions by project and device type.

Supports automatic breakdown and generation for complex scenarios such as form filling, list operations, and multi-step flows.

Token usage stats, execution reports, and related features support management and optimization of generation volume, execution results, and cost.
